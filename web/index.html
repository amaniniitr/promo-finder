Today an editor watches ~103 minutes of every new microdrama to pick promo moments, and a new show ships every week. Promo Finder reads the timestamped screenplay and returns ranked, post-ready 20–60 s promos with a week-1 posting plan, in about 7 minutes.

how it works in four steps
Code handles every timestamp and duration, so no clip can break a rule. The AI only makes judgement calls about drama.
1CODE

parse

Every line, action and sound in the script, with its exact start and end time.

2AI

tag

Gemini marks the hook lines and cliffhanger beats by ID. It never writes a timestamp.

3CODE

assemble

Every hook → cliff window that fits 20–60 s, including clips that join two episodes.

4AI

rank

TypeSafe Jev compares clips head to head, in both orders. Repeats are removed and a week-1 plan is written.

On the 50-episode show: 3,727 beats → 500 tagged moments → 176 clips → 93 unique promos → top 20 → 5 posts, with 0 rule violations.
